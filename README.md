# ConfidentialDataMasker

Модуль автоматического выявления и маскирования конфиденциальных данных в PDF-документах. Оформлен как настольное приложение для проверки результатов человеком. Работает полностью локально: документы не передаются в интернет и в облачные сервисы.

Приложение находит в документе ФИО, паспортные данные, СНИЛС, ИНН, телефоны, адреса, банковские реквизиты, названия организаций, рукописный текст, подписи, печати и логотипы, показывает найденное рамками и после проверки человеком сохраняет новый PDF, в котором эти места закрашены.

Обрабатываются как PDF с текстовым слоем, так и сканы, ксерокопии и фотографии документов, сделанные телефоном.

## Возможности

- поиск конфиденциальных данных в тексте: регулярные выражения, правила для ФИО, полей форм и таблиц, пользовательский словарь;
- поиск подписей, печатей и логотипов по изображению страницы;
- распознавание текста сканов и фотографий (Tesseract, русский и английский языки);
- выравнивание фотографий документа (перспектива, неравномерное освещение);
- редактор для проверки: принять или отклонить найденную область, изменить её тип, закрасить область вручную;
- пакетная обработка очереди файлов без проверки;
- необязательная повторная проверка трудных мест сканов локальной моделью Qwen через Ollama.

Исходный файл не изменяется. Результат сохраняется в выбранную папку с префиксом `Обработанный_`. Каждая страница результата — изображение с закрашенными областями, поэтому скрытый текст из файла извлечь нельзя.

## Требования

- Windows 10/11 x64 (проект собирается и под Linux, но проверялся только на Windows);
- [.NET SDK 10](https://dotnet.microsoft.com/download);
- для проверки моделью (необязательно): [Ollama](https://ollama.com) и модель `qwen3.5:4b`.

## Сборка и запуск

```
git clone <адрес репозитория>
cd ConfidentialDataMasker
dotnet run -c Release
```

Модели распознавания Tesseract (`tessdata/rus.traineddata`, `tessdata/eng.traineddata`) лежат в репозитории и копируются в папку сборки автоматически.

Проверка моделью включается галочкой «Проверять сканы моделью Qwen» в окне программы. Перед этим нужно установить Ollama и загрузить модель:

```
ollama pull qwen3.5:4b
```

## Работа с программой

1. «Добавить PDF-файлы...» — выбрать один или несколько файлов. Папка для сохранения по умолчанию — `redacted` рядом с первым файлом, её можно поменять кнопкой «Папка для сохранения...».
2. Выбрать файл в списке слева. Программа откроет страницы и отметит найденное рамками.
3. Проверить рамки: клик по рамке — подтвердить, правый клик — выбрать тип или не закрывать. Протянуть мышью по странице — закрасить область вручную.
4. «Сохранить PDF» — сохранить обработанную копию.

«Обработать все без проверки» сохраняет все файлы очереди со всеми найденными областями.

«Словарь названий...» открывает текстовый файл, куда можно дописать слова и названия, которые нужно закрывать всегда (например, названия своих организаций). После сохранения словаря документ проверяется заново.

## Файлы настроек

Все файлы лежат в папке `%AppData%\ConfidentialDataMasker`:

| Файл | Назначение |
|---|---|
| `dictionary.txt` | пользовательский словарь |
| `vision.json` | адрес Ollama, имя модели, таймаут, включена ли проверка моделью |
| `training_data\` | решения пользователя (принято/отклонено/добавлено вручную) и вырезанные фрагменты страниц; используются для подстройки порогов поиска подписей и печатей |

Пример `vision.json`:

```json
{
  "Enabled": true,
  "Endpoint": "http://localhost:11434",
  "Model": "qwen3.5:4b",
  "TimeoutSeconds": 600,
  "MaxRegionsPerPage": 12,
  "MaxNewLinesPerRegion": 6
}
```

## Как устроена обработка страницы

1. **Получение текста** (`Services/PageTextExtractor.cs`, `Services/OcrService.cs`). Если в PDF есть текстовый слой, слова и их координаты берутся из него. Иначе страница переводится в изображение 200 dpi и распознаётся Tesseract. Фотографии предварительно выпрямляются и выравниваются по освещению (`Services/Imaging`).
2. **Исправление ошибок распознавания** (`Services/Detection/OcrLineRepair.cs`): разделение и склейка строк, исправление типичных замен символов.
3. **Поиск в тексте** (`Services/Detection/ConfidentialDataDetector.*.cs`): шаблоны документов и реквизитов, ФИО, поля форм («Кем выдан», «Адрес» и т. п.), столбцы таблиц, значения, разорванные между строками, неразборчивый (рукописный) текст, блок «Документ подписан электронной подписью».
4. **Поиск подписей и печатей** (`Services/Detection/StampAndSignatureDetector.cs`): найденный печатный текст и линии таблиц исключаются, оставшиеся тёмные и цветные пятна делятся на печати и подписи по форме и заполненности.
5. **Повторная проверка моделью** (`Services/SecondReading`, необязательно): участки сканов рядом с подписями и печатями и плохо распознанные строки читаются моделью Qwen; найденное в исправленном тексте добавляется к результату.
6. **Сохранение** (`Services/PdfRedactionService.cs`): каждая страница переводится в изображение, найденные и подтверждённые области закрашиваются, из изображений собирается новый PDF.

## Структура проекта

| Папка | Содержимое |
|---|---|
| `Models` | модели данных: области, предложения программы, элементы очереди, примеры для обучения |
| `ViewModels` | логика окна (MVVM, CommunityToolkit.Mvvm) |
| `Controls` | холст страницы с рамками и ручным выделением |
| `Services` | рендеринг PDF, распознавание текста, сохранение результата, словарь, журнал решений |
| `Services/Detection` | поиск конфиденциальных данных в тексте и на изображении |
| `Services/Imaging` | выпрямление фотографий и выравнивание освещения |
| `Services/SecondReading` | повторная проверка моделью через Ollama |
| `tessdata` | модели Tesseract |

## Качество

Проверка проводилась на синтетических документах с автоматической разметкой: 96 документов 12 видов (договоры, приказы, доверенности, анкеты, акты, протоколы и др.) в четырёх вариантах — текстовый PDF, скан, ксерокопия, фотография; всего 1888 мест, которые нужно закрыть. Место считается найденным, если закрыто не меньше 60 % его площади (для подписей и печатей — 50 %).

| Вариант | Без модели | С моделью Qwen |
|---|---|---|
| Текстовые PDF | 1184 / 1186 | 1184 / 1186 |
| Сканы | 428 / 440 | 434 / 440 |
| Ксерокопии | 132 / 132 | 132 / 132 |
| Фотографии | 128 / 130 | 128 / 130 |
| **Всего** | **1872 / 1888 (99,2 %)** | **1878 / 1888 (99,5 %)** |

Лишних предложений (закрыто то, что закрывать не нужно): 1 из 2106.

## Ограничения

- поддерживается только PDF; Word и другие форматы нужно предварительно сохранить в PDF;
- результат — растровый PDF: текст в нём нельзя выделить и найти поиском;
- тонкие и бледные подписи на сканах иногда закрываются не полностью — результат нужно проверять;
- папка `training_data` содержит фрагменты обработанных документов и найденный текст в открытом виде, доступ к ней нужно ограничить.
